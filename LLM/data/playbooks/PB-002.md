# Playbook PB-002: Ransomware Containment & Recovery

## Purpose
Rapid containment, forensic preservation, eradication, and safe restoration procedures for systems affected by active ransomware encryption or staging activity.

## Detection Indicators
- EDR alerts indicating bulk file rename operations with known ransomware extensions (e.g., `.locked`, `.enc`, `.crypt`).
- Creation of ransom note files (`HOW_TO_DECRYPT.txt`, `README_RESTORE.txt`) in shared directories.
- Mass termination of backup processes, shadow copy deletion commands (`vssadmin delete shadows /all /quiet`), or hypervisor API abuse.
- High disk I/O burst coupled with outbound C2 beaconing.

## Triage Steps
1. Identify patient zero hostname, user identity, IP address, and active network interfaces.
2. Determine propagation vector (lateral SMB movement, RDP compromise, phishing payload execution).
3. Identify all network shares and attached storage mounted by the compromised system.
4. Verify integrity of immutable offsite and offline backup repositories.

## Containment Steps
1. **Immediate Host Isolation:** Execute EDR network isolation immediately on all identified infected hosts.
2. Sever network access: Disable switch ports, disconnect virtual NICs via hypervisor, and revoke VPN sessions.
3. Terminate active ransomware processes via EDR remote shell or hypervisor memory freeze.
4. Disable SMB / NFS file shares across the affected segment to halt network share encryption.
5. Invalidate compromised user and service account credentials across Active Directory / IdP.

## Remediation Steps
1. Re-image compromised endpoints from clean, verified golden images; do NOT attempt in-place cleanup.
2. Identify and patch the initial access vulnerability (e.g., unpatched VPN gateway, exposed RDP).
3. Validate immutable backup integrity, verify clean restore point prior to initial IOC timestamp, and restore files.
4. Deploy enhanced EDR behavioral blocking policies across all cluster nodes.

## Verification Steps
1. Scan restored environments with multiple threat scanners for dormant droppers or persistence scripts.
2. Monitor network egress for C2 communications for 72 hours.
3. Validate user access to restored data and system functionality with business owners.

## Escalation Conditions
- Lateral movement detected to Tier-0 Domain Controllers, Active Directory servers, or backup servers -> Trigger Major Incident Response Protocol and notify CISO & Legal Counsel immediately.
