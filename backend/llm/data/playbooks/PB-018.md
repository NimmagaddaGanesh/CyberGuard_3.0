# Playbook PB-018: Generic Security Event Response

## Purpose
Standard operational procedure for automated Tier-1 containment and Tier-2 escalation for Generic Security Event.

## Detection & Indicators
- Rationale: Unclassified security anomalies require immediate host isolation and telemetry extraction.
- Priority: Medium
- Response Domain: General Incident Containment

## Tier-1 Automated Containment
**Primary Action:** Isolate affected host assets, collect volatile forensic logs, and review access control policies.

### Tactical Execution Steps:
1. Isolate the impacted host/endpoint from the network.
2. Capture volatile memory and system log snapshots.
3. Perform privilege escalation and access log review.

## Tier-2 Alternate Escalation Playbook
**Escalation Trigger:** Tier-1 fails or analyst marks [ESCALATE].
**Alternate Action:** Zero-Trust Triage & Threat Surface Quarantine: Blackhole originating subnet, reset active user credentials, and initiate full DFIR investigation.
**Escalation Tier:** Senior SOC Lead & Threat Intelligence Analyst

### Advanced Containment Steps:
1. Enforce full subnet micro-segmentation at SDN layer.
2. Revoke all Kerberos/Active Directory ticket-granting tickets for the host.
3. Hand over triage dossier to Tier-2 Security Operations Center.

## Verification & Recovery
1. Verify indicators have ceased across SIEM/EDR streams.
2. Confirm memory writeback is recorded in Hindsight Cloud bank 'cyberguard-soc'.
3. Update Bayesian prior weights to reflect resolution outcome.
