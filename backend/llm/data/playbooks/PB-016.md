# Playbook PB-016: Sensitive Data Leakage Response

## Purpose
Standard operational procedure for automated Tier-1 containment and Tier-2 escalation for Sensitive Data Leakage.

## Detection & Indicators
- Rationale: Model response or retrieved RAG context contains plaintext PII, credit card numbers, or cryptographic secrets.
- Priority: Critical
- Response Domain: Data Loss Prevention & Privacy

## Tier-1 Automated Containment
**Primary Action:** Redact PII and secrets with regex/Presidio masking, block output transmission, and alert data protection officer.

### Tactical Execution Steps:
1. Mask detected credit card numbers, API keys, and PII from model output before rendering.
2. Block outgoing HTTP webhook with leaking payload.
3. Audit prompt context for source of leaked sensitive data.

## Tier-2 Alternate Escalation Playbook
**Escalation Trigger:** Tier-1 fails or analyst marks [ESCALATE].
**Alternate Action:** Vector Store / RAG Poisoning Quarantine: Purge corrupted embeddings from knowledge base and rotate exposed API keys.
**Escalation Tier:** Data Privacy & Cryptographic Security Officer

### Advanced Containment Steps:
1. Locate source chunk in vector database and delete/re-index document.
2. Immediately invalidate and rotate exposed API keys/credentials across cloud services.
3. Enforce tenant-isolated metadata filtering on all semantic search queries.

## Verification & Recovery
1. Verify indicators have ceased across SIEM/EDR streams.
2. Confirm memory writeback is recorded in Hindsight Cloud bank 'cyberguard-soc'.
3. Update Bayesian prior weights to reflect resolution outcome.
