# Playbook PB-011: Unauthorized Access Response

## Purpose
Standard operational procedure for automated Tier-1 containment and Tier-2 escalation for Unauthorized Access.

## Detection & Indicators
- Rationale: Access anomalies from unapproved locations or impossible travel times indicate active session hijacking or stolen tokens.
- Priority: Critical
- Response Domain: Identity & Session Defense

## Tier-1 Automated Containment
**Primary Action:** Terminate unauthorized user sessions, revoke active API tokens, and temporarily lock compromised account.

### Tactical Execution Steps:
1. Terminate active web and API sessions across all identity providers for the compromised user.
2. Revoke active OAuth bearer tokens and temporarily lock the account pending analyst verification.
3. Review authentication logs for unauthorized configuration modifications or privilege elevation.

## Tier-2 Alternate Escalation Playbook
**Escalation Trigger:** Tier-1 fails or analyst marks [ESCALATE].
**Alternate Action:** Privilege Escalation & Lateral Movement Quarantine: Invalidate STS session tokens, freeze assumed IAM roles, and audit cloud trail logs.
**Escalation Tier:** Tier-2 Cloud IAM & Incident Response Specialist

### Advanced Containment Steps:
1. Audit and delete newly created service accounts, SSH keys, or cloud IAM credentials created during the session.
2. Invalidate root and privilege delegation policies across cloud organizations.
3. Initiate forensic review of privileged database and storage accesses made during the incident window.

## Verification & Recovery
1. Verify indicators have ceased across SIEM/EDR streams.
2. Confirm memory writeback is recorded in Hindsight Cloud bank 'cyberguard-soc'.
3. Update Bayesian prior weights to reflect resolution outcome.
