# Playbook PB-007: Phishing Response

## Purpose
Standard operational procedure for automated Tier-1 containment and Tier-2 escalation for Phishing.

## Detection & Indicators
- Rationale: Deceptive email campaigns attempt credential harvesting or malware staging; rapid purge prevents organizational compromise.
- Priority: High
- Response Domain: Email & Identity Defense

## Tier-1 Automated Containment
**Primary Action:** Purge malicious email across all tenant mailboxes, block sender domain at Secure Email Gateway, and revoke credentials for clicked users.

### Tactical Execution Steps:
1. Execute automated search-and-purge command across all employee mailboxes matching the campaign message ID.
2. Block sender domain, originating IP, and embedded URLs at the Secure Email Gateway.
3. Force sign-out and session revocation for users identified as having opened the phishing link.

## Tier-2 Alternate Escalation Playbook
**Escalation Trigger:** Tier-1 fails or analyst marks [ESCALATE].
**Alternate Action:** Adversary-in-the-Middle (AiTM) Token Defense: Invalidate OAuth refresh tokens, enforce FIDO2 hardware keys, and scan endpoints for infostealers.
**Escalation Tier:** Tier-2 Identity & Endpoint Threat Hunting Team

### Advanced Containment Steps:
1. Invalidate all active Entra ID / Okta session and OAuth refresh tokens for targeted user groups.
2. Enforce phishing-resistant FIDO2 hardware token challenge for all external sign-in requests.
3. Dispatch EDR full-disk threat scans on recipient workstations to detect second-stage infostealer payloads.

## Verification & Recovery
1. Verify indicators have ceased across SIEM/EDR streams.
2. Confirm memory writeback is recorded in Hindsight Cloud bank 'cyberguard-soc'.
3. Update Bayesian prior weights to reflect resolution outcome.
