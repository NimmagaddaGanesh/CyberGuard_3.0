# Playbook PB-015: Excessive Agent Permissions Response

## Purpose
Standard operational procedure for automated Tier-1 containment and Tier-2 escalation for Excessive Agent Permissions.

## Detection & Indicators
- Rationale: Agent possesses broader write and delete permissions than necessary for current objective, creating blast-radius risks.
- Priority: High
- Response Domain: Agent Privilege Governance

## Tier-1 Automated Containment
**Primary Action:** Apply Least-Privilege Agent Scope (LPAS), downgrade agent session tokens, and block write actions on protected resources.

### Tactical Execution Steps:
1. Downgrade agent runtime token from admin to scoped read-only role.
2. Reject tool execution requests exceeding task requirements.
3. Audit database mutations attempted by the agent.

## Tier-2 Alternate Escalation Playbook
**Escalation Trigger:** Tier-1 fails or analyst marks [ESCALATE].
**Alternate Action:** Just-In-Time (JIT) Permission Brokerage: Revoke persistent keys and require short-lived cryptographic tokens per tool call.
**Escalation Tier:** AI Governance & Cloud IAM Architect

### Advanced Containment Steps:
1. Enforce STS short-lived credential minting with 5-minute TTL per task.
2. Invalidate all wildcards in agent manifest and bind permissions to explicit resource ARNs.
3. Audit historical agent logs for unauthorized data access.

## Verification & Recovery
1. Verify indicators have ceased across SIEM/EDR streams.
2. Confirm memory writeback is recorded in Hindsight Cloud bank 'cyberguard-soc'.
3. Update Bayesian prior weights to reflect resolution outcome.
