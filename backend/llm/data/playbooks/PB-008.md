# Playbook PB-008: Malware Detection Response

## Purpose
Standard operational procedure for automated Tier-1 containment and Tier-2 escalation for Malware Detection.

## Detection & Indicators
- Rationale: Known malware signatures or anomalous behavioral heuristics detected on host require immediate containment to stop propagation.
- Priority: Critical
- Response Domain: Endpoint Threat Mitigation

## Tier-1 Automated Containment
**Primary Action:** Quarantine suspicious binary via EDR, terminate execution tree, and isolate endpoint from internal corporate subnet.

### Tactical Execution Steps:
1. Issue instantaneous EDR host isolation command to cut network lateral communication.
2. Kill malicious process and all associated spawned child subshells.
3. Quarantine binary hash, collect sample to secure vault, and query SIEM for matching hashes.

## Tier-2 Alternate Escalation Playbook
**Escalation Trigger:** Tier-1 fails or analyst marks [ESCALATE].
**Alternate Action:** Living-off-the-Land (LotL) Deep Threat Hunt: Inspect scheduled tasks, WMI persistence, and memory injection across lateral network subnet.
**Escalation Tier:** Tier-2 Reverse Engineering & Malware Forensics

### Advanced Containment Steps:
1. Scan local registry, systemd/cron services, and WMI subscriptions for persistent hooks.
2. Capture volatile memory dump using Volatility framework to detect process hollowing or DLL injection.
3. Trigger enterprise-wide IoC threat hunt across SIEM to locate dormant lateral infections.

## Verification & Recovery
1. Verify indicators have ceased across SIEM/EDR streams.
2. Confirm memory writeback is recorded in Hindsight Cloud bank 'cyberguard-soc'.
3. Update Bayesian prior weights to reflect resolution outcome.
