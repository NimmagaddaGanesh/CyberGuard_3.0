# Playbook PB-010: DDoS Attack Response

## Purpose
Standard operational procedure for automated Tier-1 containment and Tier-2 escalation for DDoS Attack.

## Detection & Indicators
- Rationale: Volumetric or application-layer floods threaten availability of public APIs and user-facing endpoints.
- Priority: Critical
- Response Domain: Network & Edge Resilience

## Tier-1 Automated Containment
**Primary Action:** Divert traffic through BGP Anycast scrubbing center, activate L7 rate limiting, and challenge suspicious requests.

### Tactical Execution Steps:
1. Route ingress traffic through upstream Anycast DDoS scrubbing network.
2. Activate Managed Challenge (CAPTCHA/JS) and Layer-7 rate limiting on HTTP endpoints.
3. Drop spoofed UDP and TCP SYN flood packets at perimeter upstream border routers.

## Tier-2 Alternate Escalation Playbook
**Escalation Trigger:** Tier-1 fails or analyst marks [ESCALATE].
**Alternate Action:** Origin Shielding & Carrier Blackholing: Rotate origin IP addresses, restrict origin access strictly to CDN, and trigger carrier RTBH.
**Escalation Tier:** Tier-3 Cloud Reliability & SecOps Lead

### Advanced Containment Steps:
1. Re-bind origin IP addresses and enforce strict Security Group rules accepting traffic only from CDN proxies.
2. Trigger upstream ISP Remotely Triggered Black Hole (RTBH) routing for targeted destination IPs.
3. Enable circuit breakers and graceful degradation for resource-heavy backend database queries.

## Verification & Recovery
1. Verify indicators have ceased across SIEM/EDR streams.
2. Confirm memory writeback is recorded in Hindsight Cloud bank 'cyberguard-soc'.
3. Update Bayesian prior weights to reflect resolution outcome.
