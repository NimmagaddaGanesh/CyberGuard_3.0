# Playbook PB-009: Port Scanning Response

## Purpose
Standard operational procedure for automated Tier-1 containment and Tier-2 escalation for Port Scanning.

## Detection & Indicators
- Rationale: Systematic probing of network ports indicates adversarial reconnaissance targeting unpatched edge services.
- Priority: Medium
- Response Domain: Perimeter Network Defense

## Tier-1 Automated Containment
**Primary Action:** Rate-limit external SYN packets, inject dynamic edge firewall drop rules, and inspect honeypot sensor telemetry.

### Tactical Execution Steps:
1. Inject temporary perimeter firewall drop rules for the scanning CIDR IP range.
2. Enable TCP SYN flood protection and connection rate-limiting on edge routers.
3. Audit internal service exposure on targeted subnet ports.

## Tier-2 Alternate Escalation Playbook
**Escalation Trigger:** Tier-1 fails or analyst marks [ESCALATE].
**Alternate Action:** Perimeter Reconnaissance Evasion: Rotate public IP interfaces, drop ICMP/SYN discovery packets, and deploy honeynet deception tokens.
**Escalation Tier:** Tier-2 Perimeter & Network Infrastructure Security

### Advanced Containment Steps:
1. Deploy defensive honeynet deception services on probed ports to capture attacker TTPs.
2. Tighten public cloud security groups to strict IP allowlists for administrative ports.
3. Initiate External Attack Surface Management (ASM) scan to identify accidental port exposures.

## Verification & Recovery
1. Verify indicators have ceased across SIEM/EDR streams.
2. Confirm memory writeback is recorded in Hindsight Cloud bank 'cyberguard-soc'.
3. Update Bayesian prior weights to reflect resolution outcome.
